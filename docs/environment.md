# Окружение миграции

Зафиксировано на шаге 0.1.

- ОС: Ubuntu 24.04.5 LTS (Noble Numbat), Linux 6.8.0-137-generic x86_64.
- Python: CPython 3.10.15 (установлен через `uv`), venv в `.venv`.
- PyYAML: 6.0.3.
- PyGreSQL: целевая версия `6.2.3` зафиксирована в `requirements.txt`. В текущем окружении не установлена: сборка требует `pg_config` (пакет `libpq-dev`), которого нет и нет прав на установку.
- gpfdist: не установлен в текущем окружении; интеграция проверяется через fake gpfdist, реальный прогон отложен до появления кластера/стенда.
