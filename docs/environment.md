# Окружение миграции

Зафиксировано на шаге 0.1.

- ОС: Ubuntu 24.04.5 LTS (Noble Numbat), Linux 6.8.0-137-generic x86_64.
- Python: CPython 3.10.15 (установлен через `uv`), venv в `.venv`.
- PyYAML: 6.0.3.
- PyGreSQL: не установлен. Сборка `PyGreSQL==6.2.3` требует `pg_config` (пакет `libpq-dev`), которого нет в окружении и нет прав на установку. Версия будет выбрана и зафиксирована на шаге 3.3.
- gpfdist: не установлен в текущем окружении; интеграционный прогон отложен до появления кластера/стенда.
